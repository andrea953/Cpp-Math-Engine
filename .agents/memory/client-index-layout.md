---
name: Client index layout
description: Standing presentation preference for the CPP calculator's client index.
---

Keep the client index as one alphabetized row per client with the scenario count. Avoid rendering clients as section headers with nested scenario groups; keep scenario-specific actions accessible from the client row.

**Why:** The user said they dislike the grouped client layout and selected one row per client with a scenario count.

**How to apply:** When changing the calculator dashboard/client index, preserve the flat alphabetical client list. Search may match client name, scenario title, and birth year.

Provide a client-specific area for viewing and switching between that client's scenarios without returning to the full client list. Exiting to all clients should be deliberate.

**Why:** The user wants to use the calculator on screen with clients and avoid accidentally exposing the full client list.

**How to apply:** Keep in-meeting navigation within the current client, including editor return links and comparisons. Treat showing other clients as an explicit exit rather than an ordinary back action.
